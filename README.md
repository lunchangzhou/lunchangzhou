## 技术方向

- **Agent 与 AI 应用**：Spring AI、LangChain4j、LangGraph4j、RAG、Tool Calling、MCP、对话记忆与工作流编排。
- **后端与数据**：Java、Python、Spring Boot、FastAPI、MySQL、Redis、Elasticsearch。
- **前端与交付**：Vue、React、TypeScript、Docker、Nginx。
- **工程实践**：异步任务、流式交互、接口限流、数据一致性、日志追踪与问题排查。

## 业务研发经验

在继续教育平台承担前后端研发，涉及教学与财务业务：

- 支付渠道接入、订单状态流转与账务一致性。
- 考勤管理、请假补签、多级审批与统计。
- 大批量数据导出、SQL 优化与业务日志追踪。
